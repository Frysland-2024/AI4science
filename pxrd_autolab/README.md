# PXRD AutoLab bridge presets

**Role:** engineering support for auditable research workflows. The repository's only active scientific task is PXRD seven-crystal-system classification. The former parameter-inversion / Forward Loss pilot that motivated these presets is **Archived / Inactive**; this README and the old preset do not authorize it to run.

This package contains two fixed entrypoints for the local GitHub-to-GPU bridge. The forward_ab path is fail-closed: run.py produces an executable preflight report and exits blocked until its measurement-aware evidence gates and a reviewed training backend exist. It is a historical exploratory inversion preset, not the current research roadmap or a scientific result. The forward_speed_benchmark measures hardware throughput only; it is not scientific training.

## Presets

| Preset | Entrypoint | Purpose |
|---|---|---|
| forward_ab | run.py | Check the historical BaTiO3 inversion pilot config, emit machine-readable gate status, and refuse training while required gates/backend are missing. Inactive; do not use for the current classification task. |
| forward_speed_benchmark | benchmark_gpu.py | Run actual CUDA float32 matrix multiplications and record device, CUDA/PyTorch versions, free/total VRAM, and measured throughput. Hardware benchmark only. |

The bridge binds each preset to one exact config path and SHA256. GitHub Issues cannot choose a Python executable, script, shell command, arguments, or replacement config. The bridge selects Python from the administrator-controlled AI4SCIENCE_GPU_PYTHON, the documented local venv default, or its own interpreter.

## A/B gate contract

The historical forward_ab preset is intentionally blocked until machine-readable PASS evidence generated by reviewed executable tests exists for:

- structure and independent reference provenance;
- independent full-spectrum parity;
- measurement-aware expected-profile behavior;
- autograd against finite differences;
- q/eta identifiability;
- non-oracle nuisance estimation;
- split and leakage safety.

Passing these engineering gates would not reactivate the archived scientific task or grant training permission.

## CUDA benchmark

The speed benchmark is an engineering measurement only. It can allocate GPU memory and should be run only under its own approved hardware-maintenance context.

## Local checks

See the package scripts and tests for code-level bridge behavior. These checks do not reproduce the frozen classification experiments or validate PXRD parameter inversion.
