## Suggested use pattern

- Read R01 before implementing dataset-specific code.
- Read R02/R03 before making preprocessing or perturbation-physics claims.
- Read R04/R05 for framing, not to overclaim causality.
- Use R08–R12 for materials/domain context rather than as direct method specifications.
