## 核心结论

当前基于物理一致性的交叉熵优化方案，在模拟域和真实域验证中表现出性能、泛化能力与数据利用效率的改善。下一阶段拟从晶系定性判断拓展到物理参数定量反演，聚焦限定领域的专用模型，以初步晶体结构预测为落地切入点，并进一步明确具体用途。算力优先考虑按量付费的云上资源。

## 当前进展

**方法与鲁棒性。** 在交叉熵训练基础上引入 JS 一致性约束，使同一晶体结构在不同扰动谱下的输出保持一致。模拟域的 5 次随机种子训练均获得正向增益，对结构相关扰动的抵抗能力更强。

**数据与验证设计。** 从 Materials Project 获取约 14,000 个晶体结构，按训练／验证／测试 7:1.5:1.5 划分；同一结构的谱图只出现在一个划分中，避免同一母结构跨集合。采用 5 类扰动生成模拟训练谱线。

**真实域验证。** RRUFF 真实域验证保持准确率增益，真实域适配所需的数据量减少；CNRS 在 zero-shot 场景下仍有稳定提升，模型输出的置信度校准也更优。

## 后续技术方向

1. 从晶系分类拓展至物理参数的定量反演。
2. 为参数预测结果增加自洽性约束。

4. 优先从初步晶体结构预测切入，逐步明确任务范围和落地用途。
