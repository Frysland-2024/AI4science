# XRD 项目三大主要结论

**日期：** 2026-09-14

1. **总体分类性能与鲁棒性稳定提升。**  
   same-parent consistency 相比 matched Dynamic ERM，在模拟 OOD 测试与真实实验谱上都表现出稳定提升。

2. **真实域适配具有更高的标签效率。**  
   在相同真实标签预算下，consistency 预训练模型在 RRUFF few-shot 适配中获得更高性能，说明真实域迁移所需的标注成本更低。

3. **对强结构相关扰动具有更强抗性。**  
   方法在峰展宽和择优取向 / texture 这类与具体晶体衍射结构强耦合的扰动上获得尤其明显的鲁棒性收益。
