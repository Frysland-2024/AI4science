## Independent inspection of XQueryer release

User-provided archive `XQueryer-core.zip` includes `XQueryer-main/match/README.md`, `main.py`, `matched_pairs.txt`, `correct_ids.txt` and `demo_rruff.db`. The `matched_pairs.txt` has **1,698 lines but only 849 distinct pair strings / RRUFF IDs**, because each recorded pairing is present twice in this archive. Among the **849 distinct matched IDs**, **301 strict** (same elements and lattice constants within 5%) and **548 relaxed** (potentially different elements, but lattice constants within 1%). The file `correct_ids.txt` has only **641** distinct entries; it must NOT be mislabeled the complete 1,003 classification test list. The author's `match/main.py` confirms an **RRUFF ↔ Materials Project structure-matching workflow** and resampling/interpolation to 3,500 bins over 10°–80°; it does not by itself prove the upstream selection of the 1,003 classification samples.

Cao's thesis §4.2.4 (p.52) explicitly explains the distinction between **2,088 prefilter matched XY_RAW+DIF**, **1,003 valid classification samples**, **849 MP-matched structure-identification records**. This is *stronger evidence* than a conjecture that XQueryer's 1,003 are chosen for model-favorability; the documented rejection criteria are data usability, not prediction correctness. An experiment comparing scores on retained vs excluded spectra has **not** been found, so NO causal claim is supported that the curation alone raised accuracy to 91.5%.

## Existing project-local RRUFF inventory (read-only verification)

Authorized laptop `E:\AI4science\RRUFF` already contains independently snapshotted official-style ZIPs. 2026-11-03 path/central-directory inspection:
- `XY_RAW.zip`: **3,019 ZIP entries**, **3,000 distinct six-digit RRUFF IDs**;
- `XY_Processed.zip`: **1,484 entries**, **1,481 distinct IDs**;
- `DIF.zip`: **3,013 entries**, **3,006 distinct IDs**.
These are archive-level 2026 snapshot counts **not the study cohorts from 2023–2026** and not a count of eligible seven-class cases. Different revision dates and repeated files per RRUFF ID explain why raw archive numbers are not automatically comparable to papers. The official RRUFF documentation distinguishes `XY_RAW` (experimental XRD profiles), `XY_Processed` (calculated or background-processed profiles) and `DIF` (diffraction peak-list metadata); selecting which type is used has scientific meaning: https://www.rruff.net/help/zip-download/ .

## Practical owner-permitted policy for a fair high-score, clean-data RRUFF target

**We CAN curate RRUFF just as the papers do.** This is common scientific preprocessing. The defensible implementation is to define and freeze an eligibility policy *before using predictions*, then publish counts, excluded-ID reasons, final test manifest/hash, processing code and Accuracy. Do not change the acceptance thresholds after viewing model errors on a nominal final test.

1. Build a **RRUFF-valid** cohort from current snapshot: unique RRUFF IDs; parseable XY + CIF/DIF labels; one explicitly chosen reference measurement representation (RAW for XQueryer-like, processed/background-corrected for AlphaDiffract-like); documented seven-system labeling; finite intensity; sufficient angular coverage; consistent resampling on the model's specified 2θ or d-grid. Preserve both included and excluded IDs and reasons; freeze all choices before evaluation.
2. Derive named *paper-inspired* cohorts with versioned manifests: **XQueryer-like** (valid XY_RAW+DIF + min 30° 2θ span + complete cell params), **Lee-like** (initial source pool then 5°–8° STD, top 40% excluded, with explicit peak-shift-window implementation), **AlphaDiffract-like** (preprocessed spectra + DIF structural/label consistency + 20 keV compatibility/coverage; disclose calculated profiles). Paper-*like* is a much more accurate description than *exact published cohort* until sample IDs and revision are verified.
3. **Salgado** has two separate grading conditions: synthetic-only evaluation of eligible RRUFF vs **86% after 452 real labels** with honest mutually disjoint support/test IDs. If the user wants target adaptation, report real-label budget and don't position 86% as the zero-adaptation target.
4. **SimXRD Table 5 must remain Unknown cohort** until author data/exact benchmark manifest or code establishes its denominator and RRUFF ID list. Avoid making the prior unsupported claim that both Cao papers use 1,003 or that SimXRD uses 3,002.
5. Use the owner-frozen outcome goals: RRUFF seven-system top-1 **Accuracy** is the pass/80/full performance grade; independent-parent data-efficiency curve + domain-specified ECE are two separate headline research outcomes. A cohort-specific score is a *literature target*, not a strict matched head-to-head unless exact IDs, class labels, input metadata and adaptation budget are aligned. New test cohorts must not be used to steer HPO.

**Scientific bottom line:** It is entirely legitimate to report a *clean single-phase RRUFF benchmark* and a harder auxiliary raw/relaxed benchmark, and this may materially change achievable accuracies. To attribute a change in accuracy to screening, one must actually run the SAME frozen model on both cohorts; published percentages alone cannot answer it. Existing RRUFF-70/231 and previously inspected panels must stay unchanged and clearly separated from newly designed prospective cohorts.
