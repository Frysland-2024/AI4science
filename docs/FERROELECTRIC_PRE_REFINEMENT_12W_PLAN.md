# 铁电陶瓷模拟训练 AI 预精修辅助：12 周候选计划（2026-10-18）

**状态：PROPOSED / NOT_STARTED / NOT_APPROVED / NO_NEW_RESULTS**  
**建议名称：** Simulation-Trained, Calibration-Aware AI Assistance for Ferroelectric-Ceramic PXRD Pre-Refinement  
**预期周期：** 12 周；每 2 周与学长正式复盘一次（W2/4/6/8/10/12）。开始日期、材料家族、人员承诺及正式开题均待确认。  
**责任假设：** 本科生负责模拟数据、ML、概率校准、数值评估与交付；合作学长提供有限真实谱、材料/仪器背景与精修解释（可交付数据量未核实）。  
**与主线关系：** 独立下一阶段候选，不修改 `xrd_robustness/` 已冻结的 JS-only 分类研究，不宣称已获得新实验结果。

## 0. 用一句话说清目标

**不替代 Rietveld 精修**：用物理模拟谱训练 AI，面向**一个待确定的铁电陶瓷材料家族**，对有限且具参考晶体结构的**单相候选**给出经校准的 Top-K 排序、每个候选成立条件下的晶格参数初值和不确定性，通过物理正向模型检验可解释性，形成可交给实验人员的**预精修建议**。少量真实 XRD 只承担外部案例检验，不作为主要训练集。

研究问题：
- RQ1：纯模拟训练能否在可审计的未见结构/成分状态、测量扰动条件下可靠地排列候选单相？
- RQ2：相概率与结构参数区间是否有可检验的可靠性？校准在模拟外/真实域会如何退化？
- RQ3：Top-K 结构模板与参数初值能否提升传统数值精修的初始化效率/成功率，而非仅提供漂亮分类图？
- RQ4（保护性问题）：单相假设不成立（例如两相共存）时，系统能否**停止自信地给单相结论**？

## 1. 严格区分：相概率、混相比例、参数不确定性

```text
仅以互斥单相假设为候选：
  P(R 单相解释 | XRD, family)=0.70
  P(C 单相解释 | XRD, family)=0.30
  ≠ “样品中有 70 wt% R + 30 wt% C”。
```

- **单相候选后验/模型分数：** 只有在单相模型集合完整、概率经过相应数据分布校准时，才可以较有把握地称为候选相概率；否则注明 `model-estimated / simulation-calibrated confidence`。
- **两相共存：** 是另一种物理生成假设 `H_(R+C)`，不能用单相 softmax 的 70/30 直接推断混相比例。
- **参数不确定性：** 是 `p(theta | x, H_k)` 或预测区间的概念，不能由 ECE 替代；至少报告 MAE 和区间覆盖率/区间宽度。
- **ECE：** 评价一批预测概率的统计校准，不是单谱的“测得的置信度”，也不是自动变可信的训练 Loss。配合 NLL、Brier、reliability diagram；可用 validation-only temperature scaling 做第一基线。
- **物理谱残差：** 衡量解释能力，不直接等同于某个模型的概率；候选相错误、仪器失配、微结构效应、杂质/混相都可能造成残差。

## 2. 推荐范围与数据合同

**W1–2 再决定具体家族**：优先选择学长有真实样品背景且可取得参考结构的一个家族（PZT、BaTiO3、KNN 等仅为待调查例子，不预设最终选择）。范围为家族内可物理支持的约 2–4 个**具体单相结构候选**（参考 CIF/空间群/原子位点/必要的化学组成）；T/R/O/M/C 是对称性简写，**不是足以独立生成谱图的完整物相标签**。候选库必须明确成分条件和可能的非铁电相/杂质相。

模拟训练协议须记录：
- 来源 CIF、composition、空间群、仪器波长、衍射角范围、结构变形/晶格参数边界；结构改变后重新按正确几何生成衍射谱。
- 测量扰动：峰位零点、展宽、背景、噪声，必要时择优取向；物理范围可追溯，不直接套用旧模型的任意参数。
- 独立单位：母结构、近重复结构原型、成分/晶格状态与同状态测量视图分开记录；训练/验证/测试先划分再扩增，至少有可审计的结构/原型隔离测试；额外说明固定结构模板上插值的测试能证明什么、不能证明什么。
- 同时保留：训练域、模拟 OOD、与训练 forward 不完全相同的独立模拟/渲染评估（视实现可行性），以及未用于选择的真实外部案例。
- 少量真实谱需要原始 2theta-intensity、成分、波长/仪器信息、测量条件、可用参考 CIF/专家标签/精修结果及其来源；未核验真值就不报告“真实参数 MAE”。
- 真实谱若仅数条：可早期给**另选的样例**做 I/O 与物理范围 smoke；正式评估谱独立保存，冻结模型后一次性使用。若无法分开，则只能称开发案例，不声称无偏外部验证。

## 3. 最小模型与可验证输出

1. **相分类器**：复用既有 `ResNet-18-GN` 架构思路，在新家族的结构候选上重训。先作常规 CE baseline；可评估一致性版本，但不必继承旧 `lambda_js=60`；旧七晶系权重与概率**不可直接当成新相概率**。
2. **校准**：在独立模拟验证集上做 temperature scaling，报告 Top-1/Top-K、Macro-F1、ECE/NLL/Brier 与 selective accuracy/coverage。软概率只在指定单相候选域内解释。
3. **条件回归**：给每个 Top-K 候选 `H_k` 估计受对称性约束的 `theta_k`（如 cubic 的 a、tetragonal 的 a/c 等）、零点/峰宽等少量 nuisance 参数；用 MAE、覆盖率和宽度评价不确定性（ensemble 或可验证的区间回归，不从 softmax 直接造误差棒）。
4. **Forward 核验与初值**：`F_k(theta_k, instrument)` 产生理论谱，保存观察谱/重构谱叠加、残差和参考结构。与“传统候选相＋常规初值”或合理的多起点数值初始化在相同预算下比较是否省时、是否更易收敛。Forward 残差先作为**诊断/验证模块**；是否加入可微 reconstruction loss，待基础系统稳定后作为可选独立消融，不能预设有增益。
5. **失败出口**：无候选相可靠解释、异常测量条件或疑似混相时，给 `INSUFFICIENT_SINGLE_PHASE_EXPLANATION / REVIEW_REQUIRED`，附 Top-K 单相候选和异常来源；**不强迫输出唯一相**。

推荐交付格式（数值仅示例，非实验结果）：

```text
Sample X | known family | simulation-calibrated single-phase hypotheses:
  R single-phase: 0.70; a_R, alpha_R, prediction interval, fit residual
  C single-phase: 0.30; a_C, prediction interval, fit residual
  Single-phase adequacy: NOT ESTABLISHED / NEEDS REVIEW
  For refinement: test R then C with predicted starting ranges;
  if unresolved, ask expert to consider coexistence/alternative models.
```

## 4. 两相共存：纳入到什么程度？

**决定：纳入问题设置和必做安全性评估；不把自动定量相含量设为这 12 周成功的必要条件。**

### Tier A — 必做：混相作为 out-of-assumption 压力测试

- 在可核验的两个相模板下合成少量单相及代表性混相谱：`I_mix(q)=s_1 I_1(q)+s_2 I_2(q)+B(q)`（共享仪器条件；系数是模拟的衍射强度权重而非未经校正的 wt%）。
- 例：T+R、R+C、O+T **仅当家族和相结构真实合理时才选择**；覆盖不同相贡献、峰重叠、噪声与峰宽情形。
- 对“完全未见的混相谱”检查模型是否错将其以高置信度认成某一单相；查看校准概率、Top-K、所有单相 Forward 拟合残差、拒判率。
- 若单相模型均拟合不好，只能报告“单相解释不足／需要复核”；**不能仅凭高残差证明存在混相**，其他结构错误和仪器效应同样可能致残差。
- 这部分可作为未参与训练与阈值选择的混相压力测试；若以后训练拒判/混相检测器，必须另设开发/验证混相集及完全独立测试集，避免用测试集调整阈值。

### Tier B — 有条件扩展：提示“可能存在两相候选”

仅当 W8 前有足够可信相模板、混相模拟与可辨识峰时，尝试：
- 添加独立的 `single-phase inadequacy / possible mixture` 筛选器，或在单相拟合失败后对有限 `H_(i+j)` 做物理双相拟合，比较相模型复杂度与拟合改善；
- 这是**候选提示**，不是证实共存；简单叠加谱能否模拟实际晶界/织构/微应力等效应须另验证。
- 避免 softmax 只对 R/C 单相归一化以后又报告“共存概率”。可以分别呈现单相排序与“单相是否足够”判断。

### Tier C — 不作本期必达：两相质量分数/体积分数定量

需要显式多相衍射结构模型、尺度因子和相应 Rietveld 校正/参考真值；`softmax(R)=70%` 及 `s_R/(s_R+s_C)` 均不能无条件当作相 wt%。真实谱数量少时尤其不承诺定量误差验证。留到后续独立阶段，并以数据与物理条件判断是否启动。

## 6. 成功判据、停损与责任边界

**最小成功（MVP）**：在预先规定的一个材料家族/单相候选集合上，完成模拟训练的 Top-K 相建议、经**模拟域**评估的概率校准、候选条件参数估计、Forward 物理核验及可用的精修前报告，并诚实提交至少一组单相失配/混相压力测试及可获得的真实域案例（若有）。

- **W2 Scope Gate**：若相/原型模板稀少或结构身份不清，降低候选相数；先核验模拟物理而非承诺全家族泛化。
- **W4 Model Gate**：若相间真实可辨性差，优先输出 Top-K＋不确定，不强制单一预测；可用传统前向模型比较作保底。
- **W8 Integration Gate**：若回归不能稳健估参数，先交付相候选概率＋物理拟合初值/范围，不掩盖失败。
- **W10 Coexistence Gate**：Tier A 必须报告误认/拒判风险；Tier B 仅在基础功能成熟时触发，绝不替代主目标。
- **W12 Domain Gate**：真实案例极少或标签不独立时，不声称真实域 ECE、真正标定的 70% 概率，亦不声称已自动定量混相。

项目评价优先：Top-K 命中、Macro-F1、ECE/NLL/Brier、回归 MAE/区间覆盖率、物理拟合残差、误认/拒判、实际精修收敛成功率与计算时间。使用与材料表征问题相称的合理实验规模，不为了过强形式要求扩大模型搜索或实验轮数。

## 9. 新的前置构想：多材料家族路由 + 分家族专家（DISCUSSION / NOT YET ADOPTED）

**提出时间：2026-10-18；状态：可选架构候选，尚未决定纳入 12 周必做任务，更非已有模型/结果。**

本次讨论的新思路是：面向 PZT、BaTiO3、KNN 等不同铁电陶瓷体系，分别整理有据可查的参考 CIF/相库、物理参数范围、模拟谱生成协议、相候选模型和单独的模拟域概率校准器；采用统一输入、输出与 Forward/refinement 接口，通过 **Material Family Router** 将实验数据发送到相应专家模块。

**核心物理边界：**
- 实际做精修时，样品名义化学组成往往已知；默认用**实验人员填写的材料/成分元数据**确定家族。若不知道成分，则提示补充或列出待核验候选，**不能把谱图本身稳定地识别为 PZT/BaTiO3/KNN 当作前提**：部分钙钛矿结构峰位、峰形可能相似，XRD 不能普遍唯一识别化学组成。
- 自动家族识别（尤其 unknown/OOD/reject 处理）是**独立的可选上游研究任务**，需训练集、校准集和跨体系评估；不得与结构相识别任务混为一个成绩。
- 下游的相概率是 **P(phase hypothesis | XRD, known family, model coverage)**；路由错误会使整个下游相预测、参数和模拟域校准失效。应允许 `FAMILY_UNKNOWN / MISMATCH / REVIEW_REQUIRED`，对元数据与模拟/谱图严重不一致时不强制输出。
- 不同家族的 T/R/C/O/M 只代表结构对称性类别，分别需要真实物理模板/成分边界；一个家族的校准温度和参数回归头不可无验证地跨家族复用。对于显式共存假设，仍须区分 `P(R+C hypothesis)` 与 R/C 质量分数。
- 可实现为 `family registry: {templates, simulator_config, classifier, calibrator, conditional_regressor, forward/refinement config, valid_domain}`；共享代码骨架，专家头/模型是否独立训练由有限对照决定，**先不要预设每个家族都需完全独立的大网络**。

**12 周控制建议（尚待认可）：**
- **MVP 不变**：先选定一个家族，完成原计划 W2–W12 的可复现闭环，包括混相压力测试。
- **W1–2**：仅在元数据 schema/路由接口上预留 `family_id`，并列出未来能支持的其他家族（不能以此耽误首个相库与模拟协议）。
- **W9–12 有余力时**：用第二家族的少量参考结构接通配置、物理模拟与统一输出的最小 smoke demo，若缺真实数据则只作为工程可扩展性演示；**不声称完成第二家族统计学可信的分类/校准/实验域验证**。
- 独立前置家族分类器和多家族联合训练留待首个家族科学任务通过后决定，不把三家族均训练完成写成第 12 周验收要求。

**思路演化说明：** 单家族选择最早是为了控制科学变量，不是系统必须永久只支持一种材料。本次提出“多家族专家模块化”以平衡工程扩展性与科研可控性；由名义成分路由优先于自动识别家族，是为了避免凭 XRD 强行推断化学身份。原计划仍是正式候选主范围，本文仅保留此后续可能改变设计的分支。

**决策记录：** 2026-10-18。此前曾先想任意铁电陶瓷多相 → 再讨论只做单相候选 → 澄清真实谱极少而主要训练走模拟库 → 提出“70% R / 30% C 候选概率＋各候选参数＋不确定性，用于精修前” → 决定以**单一材料家族内的概率化单相候选预精修**为 12 周核心，**两相共存作为必做失配压力测试与可选研究分支**。此为规划定稿版本，不是实验或导师已批准的事实。

> **2026-10-18 文献纠偏（本计划仍为候选）：** 对照 2025 年 CrystalShift、2021 年 PQ-Net 等先例后发现，“物相组合概率＋对称性参数反演＋物理谱图比较”已有成熟公开研究。**Forward Model 不能仅作为模拟数据生成器**：建议同时用于推理阶段的候选物理拟合/局部反演，并以纯物理、纯 NN、NN+Forward 三组合理基线判断 AI 的增量价值。训练期可微重构 Loss 仍是独立可选消融。参见 [文献与 Forward 方法定位](PRE_REFINEMENT_FORWARD_MODEL_RELATED_WORK_20261018.md)，本次没有启动新的模型训练或推翻旧 NO-GO。

### 2026-10-18 方法优先级再讨论：Forward Reconstruction Loss 是否应直接作为主方法？

**状态：DISCUSSION / CANDIDATE / NOT STARTED**；用户明确提出：为什么不直接训练带 Forward Reconstruction Loss 的 NN？先前“重构 Loss 仅作为可选消融”的工程保守安排**不是物理/算法不可行判定**。该讨论暂不改变 W0 已授权范围，也不是新增实验结果；需要经正向物理可微数值检验、候选相模型/相共存参数化和数据拆分核验后再确定正式研究协议。

**建议首选新方法候选**：一个基于已知材料家族和有限候选 CIF 的 *supervised physics-guided inverse network*，输入 PXRD，联合输出（a）候选相/相组合得分，（b）候选成立条件下的晶格及少量仪器参数，（c）若显式考虑混相，则是非负的相激活/尺度因子；用经验证可微的 PXRD forward `F_H(theta, nuisance)` 重建谱，采用 `L = lambda_phase L_phase + lambda_param L_param + lambda_recon D(F_H(theta_hat), x)`。其中 phase 分支的梯度是否来自重构项取决于具体连续化/混相门控实现：**若训练时直接使用真值相选择 F_H，重构梯度只会约束参数头，不会自动训练离散分类头**。如果训练 explicit single/dual mixtures，模型选择和物理强度权重必须区别于相概率、质量分数。

**理由及先例**：[Chen et al., *Nature Machine Intelligence* 2021](https://doi.org/10.1038/s42256-021-00384-1) 的 DRNets 将重构与约束推理共同用于相图分解，已经说明类似架构有先例，不能凭“可微 forward loss”独立声称新算法原创；[CrystalShift 2025](https://doi.org/10.1038/s41524-025-01627-0) 则为物理-only 强基线。

**具体前置风险**：旧 `xrd_inversion` 仅验证已知四方单相数值，不意味着其它相与混相强度前向正确；匿名结构原型跨 split 需重新审计；局部 nominal-start capture 曾失败；高峰强度主导的重构项、参数不可辨识、仪器/纹理/背景失配、可微硬选相、混相分数与概率混淆都可能导致似是而非的结果。特别是训练数据与 loss 均来自同一模拟器时，重构 loss 可能与已有监督信息高度重合，不保证泛化收益。

**最小可行对照**：A = `CE + parameter loss`；B = `A + differentiable forward reconstruction loss`；另与 physics-only (CrystalShift 类) 比较，必要时检查 B + 局部精修。首先限定单相且相模板给定，检查参数 MAE/正确梯度和反演可辨识性；再尝试少量明确物理可辨的单/双相结构假设与非负混相强度，不一上来让网络同时学习全部家族和复杂混相。评价应包括相选择、参数 MAE、重构残差、校准、数值初值是否更有用，以及成本；保留无增益结果。

**决策边界**：该方向在研究问题上优先考虑，但 **尚需用户确认正式改动方法优先级并通过 W1–2 feasibility gate**。历史旧 proposal、旧失败 Stage-1 与冻结 V9 不被覆盖。
