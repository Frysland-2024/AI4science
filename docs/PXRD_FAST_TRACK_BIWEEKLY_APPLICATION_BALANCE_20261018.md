## 5. 三道红线 / 停损

1. **物理与数据红线：** 新模拟研究必须过 forward/梯度验证、母结构/原型 split 审计；不得用旧四方数值 PASS 直接推断新陶瓷 PASS，不碰独立 frozen renderer。
2. **科研结论红线：** A/B 若无改善或恶化，保留结果；Forward Loss 不是原创算法；模拟同源 forward 上的收益不能自动宣称真实谱有用。学长未确定材料前不能把临时 smoke 包装成正式材料研究。
3. **时间红线：** 一旦申请 deadline 或课业高峰临近，除数据保存、预约会议、必要计算监控和已有合作义务外，不再加模型、新材料家族、混相定量、家族路由和额外 loss。
