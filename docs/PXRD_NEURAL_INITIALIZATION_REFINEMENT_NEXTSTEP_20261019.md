## 0. 零基础中文版：我们到底在干什么？

**最简单一句话：AI 先猜一个接近正确的晶格参数，物理计算再调整它，直到生成的衍射峰尽可能匹配测到的谱。**

把谱图想成一串“材料的指纹峰”；a/c 是晶格大小（影响峰位置），δ 是仪器角度零点误差，FWHM 是峰宽，背景和噪声是额外测量因素。传统精修已经能通过计算参数→生成理论谱→比较→再次修改参数来解方程；AI 不负责取代这条物理推理，只负责给它一个更合适的**起跑位置**。

1. **人指定候选材料/结构模板（CIF）和波长**：不要求 AI 从任意输入谱独立猜出完整晶体化学式。旧七晶系分类器最多提供弱的辅助提示，不是物相识别器。
2. **AI 看输入一维 PXRD，快速提出参数初值**：四方晶格可先输出 a、c 的有限范围；是否预估 δ/FWHM，取决于对应网络训练标签与适配验证。
3. **物理 forward**：按该结构模板及参数计算一张期望 PXRD（把允许的仪器偏移、宽度、背景包含进去），与用户测到的实际输入比较。
4. **数值优化器反复改参数**：它直接沿着减少理论谱与输入谱差异的方向更新 a/c、零点、峰宽等，直到收敛、超时或识别不可辨识/拟合失败。
5. **输出可验证结果，而非漂亮图片**：最终参数（Å）、与输入的谱图叠加和差谱、目标函数、参数是否撞界、来自多个初值的稳定性、拒判/人工复核提示。低残差不是参数正确的充分条件。

**简单类比：** AI 帮忙把地图上的起点圈在附近；物理优化沿道路导航找目的地。真正待证明的是 AI 给的起点，是否比传统人工/均匀多初值起点更省时、更稳，而不是导航能否到达（传统方法本来就能做）。

## 1. 为什么转向：有证据，也有反证

### 已经证明的狭窄事实
- 在**一个公开 BaTiO3 P4mm CIF 的合成数据插值**上，物理可微 forward 和联合参数优化链路可以运行。2026-10-19 新审计：V9 归一化 q-MAE 直接回归 A=0.03531、B=0.03238、D=0.04618；联合 q+eta L-BFGS-B 精修后 A=0.000439、B=0.000400、D=0.000437；全部 1,386 次网络初值精修调用优化器报告成功（不等于 1,386 种真实材料）。
- D 加入 zero-shift 标签，V9 zero-shift RMSE 改善约 53.1%，但是 q-MAE 比 B 恶化约 42.6%，且三 seeds 都更差。不能继续假设“改进 nuisance 头必然改进晶格参数”。
- 固定中性初值 physics-only 在同批 V9 的 q-MAE 为 0.01664，明显弱于 AI 初始化后再精修；**但另一次 DONUT-PXRD Exp4 的三起点物理-only 可达到约 0.000359**。这两次数据、初值与协议不同，不能据此声称 AI 胜过强传统优化。我们的下一步必须公平比较这一项。

### 还没有证明的事情
- 真实 XRD 的晶格参数准确率和稳定性；跨 CIF/成分泛化；多相或完整 Rietveld 精修能力。
- 混合精修在相同总算力/运行时间/成功率要求下，是否胜过合理的传统多起点策略。
- 单凭重建谱接近，就能确定晶格参数与仪器参数唯一且正确。

**因此核心研究问题改为：在已知候选单相结构的 PXRD 反演中，神经网络初始化是否提高有界物理精修的效率、收敛可靠性或最终可信度？对哪些真实条件失效？** 这是未来要检验的假设，不是已有结果。

## 2. 工作范围（本科最小完成版本）

**先做：** 人知道一个候选材料/结构家族；单相、可查证同谱/参考晶胞的有限晶格自由度（如 cubic 只有 a、tetragonal 有 a/c）；仪器波长已知；初期用可复现的公开数据与本地保存的真实谱开发案例。

**不做为必需：** 任意物相自动识别、全部七晶系通用端到端精修、多相 wt%、原子坐标全自由度精修、用 LLM/Qwen 代替物理模型、强行宣称超越 Rietveld、无来源真实标签学习、大规模无限超参搜索。

**保留并行工程：** phase-router 是可展示的候选库/软件接口（人工候选 CIF、可选七晶系弱先验）；它不是参数反演方法取得科研增益的自动证明。

## 3. 分阶段执行方案（只有下一步被单独授权才启动实验）

### P0 — 合同化任务/证据，优先级最高
- 确定一个**物理上最容易检验**的单相家族和至少一小批有波长、原始 2θ 强度、结构/成分参考的真实谱；按来源记录仪器信息、许可、参考晶胞究竟是否为同一样品。若只能得到不同样品的 CIF，真值标为“不足”，不能计算假精度。
- 若 Garnet 继续多初值不稳定，就先停，不应为复用 44 条标签强行训练；Rutile 精确配对数只有约 10，可能只能做小规模案例，不足以支撑广泛监督适配结论。
- 确保候选 CIF、二维转一维坐标和 forward 源码、波长、峰形、归一化、背景处理、有效角度范围全有可追溯记录；评估低质量/混相谱的拒判策略。

### P1 — 在真实谱上把传统 Physics Baseline 做扎实
- 对同一条谱先固定 CIF 并做 full-profile/Bragg reference parity、梯度检查、参数边界和局部可辨识/多起点稳定性。稳定性没有过关，停止，不训练 AI 来“掩盖”问题。
- 同样物理模型下建立普通固定/中性初值、预定义网格或随机多起点、材料专家合理起点几类 baseline；记录最佳残差也记录所有重启次数/失败/结果分歧/运行时间。
- 即便 profile residual 很小，也要同已核验参考晶格参数/峰位偏差比对；没有独立真值就写拟合一致性，不写参数 MAE。

### P2 — 仅复用已有已验证神经网络做初始化
- 先检查当前 BaTiO3 checkpoint 的数据预处理/结构模板/目标参数和新目标域是否兼容；不兼容就不直接使用，标注“需要限定家族模拟训练或少量真实校准”，在明确新数据协议后另行决定。
- 固定同一批输入、相同物理优化边界、同样 max iterations / tolerances / forward 版本。比较 NN 初值、传统合理初值和多起点 baseline。使用训练/验证数据选择任何参数，不使用独立测试的结果调模型。
- 可选比较 A（纯参数监督）和 B（参数监督＋重建 Loss）输出初值是否有不同效益；不把新 Loss 成功设成毕设存活条件。

### P3 — 公平评价与“价值判断”
主要指标（按当前可获得的真值程度取舍）：
- **主指标：** 在固定物理模型的**实际晶格参数 MAE（Å）**、收敛成功率和多起点输出稳定性；若没有可靠同一样品参考，主报告仅保留可观察的一致性与无法验证标签。
- **工程指标：** NN 一次预测耗时 + 物理优化耗时 + 需要重试次数 = 完整端到端时间；与多起点 physics-only 的完整成本比较，不只看某次最优 RMSE。
- **辅助：** observed-profile RMSE、强峰覆盖/峰位差、参数撞界、失败/拒判率、明显错误相模板时的失配反应。
- 所有方法同一波长/轴、合理噪声/背景模型、预定初值策略和有限预算；报告三个以上 seeds/多个真实样品时不得把同一重复样品当成独立泛化。指标预先固定；失败如实写。

### P4 — 交付给谭启或毕业答辩
- 最小可运行的本地演示：选择/上传谱，人工选结构候选，显示 AI 初值、精修后参数、预测/输入谱叠加、差谱、参数/拟合置信限制和运行成本对照。
- 一页“项目历史：成功与否如何改变了目标”，一页“公平对照：AI 初值 vs physics-only 多起点”，一页“真实谱与应用边界”；实验参数、来源和脚本可追溯。
- 如果 AI 不如传统多起点：仍能给出客观的可复现负结论和系统工程演示，**但不可把它叫做验证了 AI 改善精修的科学结果**。若真实谱 Forward 模型仍不稳定，退回“真实域模型失配和反演可靠性诊断”或更小的合成受控研究，不无限换模型救结果。

## 4. Gate、停止条件和状态

| Gate | 允许继续的最低条件 | 不满足时 |
| --- | --- | --- |
| 数据/物理 | 候选结构/波长/谱的可追溯身份；forward 与参照强峰/整体强度基本一致 | 仅做数据与物理诊断，不训新 NN |
| 参数可恢复性 | 已知真值 synthetic recovery + 多初值稳定性，测量参数允许非 oracle 拟合 | 降自由度、改物理近似并重新登记新 Gate |
| 公平对照 | 同样优化器、范围、预算、测试集；NN 预测时间计入成本 | 不声称提升 |
| 真实结论 | 真实谱来源和同样品标签可信，失败案例完整保留 | “真实谱可视化/拟合案例”而非真实参数泛化 |
| 工作范围 | 单相、已知候选、人参与 | 其他任务独立立项，不追加到最小毕设 |
