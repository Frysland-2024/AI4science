# Public BaTiO3 CIF

- COD entry: [9014273](https://www.crystallography.net/cod/9014273.cif), tetragonal BaTiO3, P4mm (#99).
- Historical structural reference recorded by COD: G. Shirane, H. Danner, R. Pepinsky, *Physical Review* 105, 856 (1957), DOI: 10.1103/PhysRev.105.856.
- The CIF is copied byte-for-byte from the public-CIF pilot branch; SHA-256 is recorded in `measurement_closure/audit_run_v3/p0_p1_audit.json`.
- Scope is one known structural template with fixed fractional coordinates. This study is not a full-structure refinement and makes no experimental PXRD claim.
