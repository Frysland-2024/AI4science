# Preregistration: cross-material neural initialization pilot

Frozen before any held-out profile is generated/evaluated. Date: 2026-10-19.
This separate synthetic known-candidate pilot does not modify previous classification or inversion studies.

## Material matrix and source integrity
The canonical config.json plus materials.json and source_audit.json define identities, pinned bytes, citations and sourcing failures. Required first pilot: BaTiO3, MgO, CeO2. Then rutile TiO2, ZnO, silicon, grossular. Calcite and corundum are provenance-verified but unsupported trigonal parameterizations and must be SKIPPED, not mapped to cubic/hexagonal. Twelve distinct candidate IDs were attempted, nine legitimate identities sourced; two identity mismatches FAIL and forsterite download BLOCKED remain preserved. More cubic materials do not constitute more crystal systems. No new candidates after freeze.

## Physical model and gates
Cu wavelength 1.5406 Angstrom; 1024 increasing 2theta samples from 15 to 85 degrees. CIF fractional coordinates and occupancies fixed. Actual angle-dependent atomic scattering factors, structure-factor sums and Lorentz-polarization recomputed for each q. Kinematic Gaussian powder profile; no atomic displacement refinement, texture, doublet, multiphase or full Rietveld claim.
q=(cell/reference_cell-1)/0.02: cubic a only, tetragonal/hexagonal a,c. Fit bounds [-1,1]; parent draws [-0.8,0.8]. Actual lattice-cell errors reported per coordinate in Angstrom; never pool distinct DOF across materials.
eta=(zero shift deg, FWHM deg, intensity scale, background offset, background slope). Neutral [0,.32,1,.02,0]; bounds [-.12,.12],[.22,.44],[.75,1.25],[0,.08],[-.04,.04].
Gate thresholds fixed in physics.GATE_THRESHOLDS: independent pymatgen position <1e-5 deg, relative intensity <2e-5, at least 3 peaks; numerical Jacobian condition <1e7 at three q points; step-halving derivative relative discrepancy <.01; non-oracle noiseless best q error <.06 and RMSE <.003; multistart q spread <.12 at two development cases. Site geometry additionally requires positive volume, minimum intersite distance >0.5 Angstrom, site total occupancy in (0,1.001], and expanded space group matching the source record. Bounds, positive/distinguishable finite profiles and lattice symmetry must also pass. Independent parity failure HALTS all GPU research. Recoverability failure skips material without threshold changes. These are synthetic development gates, not claims of real-domain readiness. No gates are relaxed after seeing cases.

## Data and training
Per material 512 independent q parents, split 358/77/77 before nuisance/noise using fixed permutation. Base seeds in config; material-specific SHA256(id) first eight hex digits interpreted as integer is added to parent, nuisance and noise seeds, ensuring independent material draws. A sample's noise uses SeedSequence([material_noise_seed,parent_index]). All methods and three NN seeds use exactly paired test observations.
V9-like primary only: shift U[-.10,.10] deg, width U[.24,.42] deg, scale U[.8,1.2], offset U[.02,.06], slope U[-.015,.015]. Poisson 15000 counts per unit intensity plus Gaussian sigma .002. These are new controlled nuisance ranges, not literal full V9 (no preferred orientation). No test observations generated until all three selected models saved.
MLP input1024 ->256 SiLU ->128 SiLU ->q Tanh; supervised q MSE only. Train-only pointwise mean/std (floor .02). Adam lr .001, batch32, clip5, 24 epochs, three seeds [2026101911,2026101912,2026101913]. Select lowest validation q MAE, earliest epoch on tie. No lambda/model search. Final best state weights only, ignored privately. Training on CUDA, inference measured CPU one spectrum at a time. Full train/validation curves, best epoch, model hash, training time retained.
N+B SKIPPED because renderer is NumPy and has no autograd reconstruction implementation. No D or DONUT. Low-noise and independent-renderer stress NOT_RUN to prioritize bounded diverse-material primary; this is an explicit scope limitation.

## Comparison and compute fairness
Every fit uses same physics.PowderModel.fit: L-BFGS-B, observed profile MSE, identical bounds, neutral eta, maxiter100 maxfun1000, ftol1e-12 gtol1e-7 maxls30, numerical derivatives. No true q or eta in start selection or optimization. Truth only supplies training labels and posthoc held-out scoring.
P0: q=zeros. P3: three predeclared diagonal starts q=zeros, all -0.5, all +0.5, choose solely minimum observed residual, count all three times and evaluations. N+A: each seed's single network q prediction plus same neutral eta, same optimizer. Paired inference latency included; training separately both amortized across test predictions and nonamortized.
Additional equal-evaluation-ceiling sensitivity: total maxfun600 for P0 and N+A; P3 each maxfun200. SciPy finite-difference batches may exceed maxfun; actual nfev always reported. This sensitivity matches allocated function-evaluation ceilings, not measured wall time or guaranteed exact evaluation counts. Full primary P3 has three times allocated evaluations; no false equal-compute claim.
Record every attempt, exit/failure, q/lattice error, residual, convergence, any-boundary hit, start disagreement, actual nfev, mean/median/p95 end-to-end time, full per-seed summaries. Deterministic P0/P3 run once on shared77, not replicated as independent seeds.

## Decision rule (exploratory three seeds)
Accuracy advantage requires every NN seed q MAE <95% P3, each cell-coordinate MAE <=105% P3, mean inference <=110% P3, and convergence >=P3. Runtime Pareto requires every NN seed q and each cell MAE <=105% P3, mean inference <80% P3, convergence >=P3, boundary rate <=P3. Either also requires every NN seed equal-ceiling q MAE <=105% equal-ceiling P3. Otherwise state NEGATIVE FOR NEURAL INCREMENTAL VALUE. These tolerances are prespecified descriptive practical comparisons, not significance thresholds; report raw values and seed dispersion regardless. No changing rule to rescue an outcome.

## Execution, failure and delivery
One sequential manager lock. <=8h wall from pilot start, <=4h measured CUDA training, <=10 validated templates and <=10GB. Check compute jobs, never disturb processes. Persist budget before/after each seed; check within training/sample loop and between materials. Historical attempts immutable; no automatic retries, at most one separately reviewable code-bug retry before any opened test. Interrupted test attempts blocked from automatic resume. Freeze config, prereg, all source and CIF hashes; hash mismatches block resume. Preserve all failures and NOT_RUN statuses. A gate skip or inaccessible source is a documented shortfall, not silently discarded evidence.
Report method/material results without cross-DOF pooling. Family-specific models demonstrate workflow portability only, not zero-shot transfer or experimental validity. Commit and push this isolated branch only; draft PR, never merge.
